# 🎭 Playwright Automation Framework with Page Object Model

This repository contains a structured automation testing framework built using **Playwright** and the **Page Object Model (POM)** design pattern. 
The goal of this project is to showcase modular, scalable, and maintainable end-to-end UI tests for web applications.

## 🚀 Tech Stack

- **Automation Tool**: Playwright
- **Language**:JavaScript
- **Test Runner**: Playwright Test
- **Design Pattern**: Page Object Model (POM)
- **Reporting**: Playwright Reporter
- **CI/CD Integration**: GitHub Actions


## 🎯 Features

- Organized using Page Object Model for maintainability
- Supports cross-browser testing (Chromium, Firefox, WebKit)
- Built-in screenshot and video recording on failure
- Parallel and selective test execution
- Supports environment-based configuration
- Clean and easy-to-read test syntax

## 🧪 Sample Test Scenarios
- Login functionality validation
- Form input and validation testing
- Page navigation and assertions
